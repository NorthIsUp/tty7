---
title: "The new tab page"
description: "New Tab asks what to open and where: a terminal or an agent, in a directory from your tabs, your most used, or your project roots."
---

<kbd>⌘ T</kbd> opens Search Everywhere on its **New Tab** tab instead of a
shell, from wherever the keyboard is; <kbd>⌘ P</kbd> and <kbd>⌘ K</kbd> switch
to its other tabs. The row under the query picks what to open — **Terminal**, or any coding agent on your `PATH` that **Settings → Agents** leaves on in
its **In New Tab** column, starting on the one you launched last. The list below picks where.

The directories come from the tab you are in, your other tabs, the directories
you open most, and the folders inside each `dir_roots` entry (`~/src`, `~/code`
and `~/projects` by default). Type to filter them; a path you type that exists,
such as `~/src/new-thing`, is offered first.

| Key | Does |
| --- | --- |
| <kbd>↑</kbd> <kbd>↓</kbd> | Move through the directories |
| <kbd>Tab</kbd> / <kbd>⇧ Tab</kbd>, <kbd>⌘ ⇧ ]</kbd> / <kbd>⌘ ⇧ [</kbd>, or <kbd>→</kbd> / <kbd>←</kbd> with nothing typed | Next / previous kind |
| <kbd>⌘ 1</kbd>…<kbd>⌘ 9</kbd> (<kbd>Ctrl 1</kbd>… elsewhere) | Pick a kind by position |
| <kbd>Enter</kbd> | Open it |
| <kbd>⇧ Enter</kbd> or ⇧-click | Open it in the background: the tab starts, and you stay where you were |
| <kbd>Esc</kbd> or a click outside | Close without opening anything |

Remote workspaces keep the plain New Tab. Set `"new_tab_page": false` in
`config.json` to turn the page off everywhere.

## Splits

<kbd>⌘ D</kbd> / <kbd>⌘ ⇧ D</kbd> open the same page, and what you pick opens
as a split beside the focused pane instead of a new tab. The page starts on the
pane being split: its directory is selected, and its kind is whatever runs
there — Codex for a Codex pane, Terminal for a plain shell or an agent the page
does not offer. A split of an SSH or remote pane still dials the same host
again.

Two settings under **Settings → Agents** decide what the page asks:

| Setting | `config.json` | Values |
| --- | --- | --- |
| **Split runs** | `split_harness` | `terminal`: a plain shell. `same`: what the pane runs, its agent started fresh or a shell. `choose` (default): the page asks |
| **Split directory** | `split_dir` | `same`: the pane's directory. `choose` (default): the page asks |

When only one is `choose`, the page still opens, with the other fixed: a single
kind on the row, or the pane's directory as the only row. When neither is, ⌘D
splits straight away; `terminal` and `same` is upstream's split. An older
`"split_page": false` is read as that.
